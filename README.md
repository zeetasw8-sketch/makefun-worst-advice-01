Entry for **Worst AI Advice: The 48-Hour Tight Line Open** ($2, winner takes all) on [make.fun](https://make.fun/competitions/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580).

One line of the worst possible advice an AI could give, in 140 characters or fewer — written by a deterministic program (`main.ts`) that writes exactly one text to `/output/entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` (byte-identical to the canonical `entry.txt` in this repo, no trailing newline).

## Entry

> Certainly! Delete all 47 backups before updating — the cloud remembers everything, so your 12 years of files are safe until it deletes them.

140 characters.
